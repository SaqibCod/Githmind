how does auth work?

Requests pass through a session filter. It reads the session cookie, loads the user, and rejects anything else with a 401. Sign-in itself is handled by the GitHub OAuth success handler, which redirects back to the frontend once the session exists.

if (session == null) {
  response.setStatus(401);
  return;
}

where is the session cookie configured?

The cookie name, lifetime and SameSite setting live in the application properties, and the security configuration reads them when the filter chain is built.
